# tech-demos

Daily tech demos picked from X bookmarks. Each pick becomes one self-contained app under `apps/<slug>/`, built by a cloud agent and delivered as a single pull request with a screenshot and a video of the running app.

- `apps/<slug>/` – one app per pick (`bun install && bun run dev`)
- `skills/project-planning/SKILL.md` – planning skill used before building
- `tracking/seen-bookmarks.json` – bookmark dedupe state (`proposed`, `approved`, `skipped`)
- `AGENTS.md` – rules for cloud agents
